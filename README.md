# PSUSphere – Student Organization Management System

## Project Description
PSUSphere is a Django-based web application designed to manage student organizations, students, colleges, and academic programs. The system allows administrators to manage organization memberships and student records efficiently using the Django Admin interface.

This project was developed as part of a Django hands-on activity to demonstrate project setup, app creation, model creation, admin integration, and database population using Faker.



## Features

- College Management
- Academic Program Management
- Student Organization Management
- Student Records Management
- Organization Membership Tracking
- Django Admin Dashboard Management
- Automated Fake Data Generation using Faker



## Database Models

The system includes the following main models:

- College
- Program
- Organization
- Student
- Organization Membership
- Base Model (timestamps and status fields)



## Technologies Used

- Python
- Django
- SQLite (Default Django Database)
- Faker (for test data generation)
- Git & GitHub (Version Control)
